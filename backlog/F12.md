## Besoin utilisateur

Trouver une commande ou rejoindre une activité rapidement.

## Critères d’acceptation

- [x] Ouvrir avec Ctrl + P ; conserver Ctrl + Maj + P comme alias proposé.
- [x] Rechercher les commandes, workspaces, onglets et panes.
- [x] ↑/↓ sélectionne, Entrée valide, Échap ferme ; faire défiler la sélection en vue.
- [x] Revenir au premier résultat après filtrage et ne rien exécuter sur liste vide.
- [x] Afficher la sélection par le fond uniquement et déclencher les éditeurs inline appropriés.
- [x] Restaurer le focus correctement sans perdre la saisie terminal.
