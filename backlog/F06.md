## Besoin utilisateur

Nommer une activité directement dans la barre d’onglets.

## Critères d’acceptation

- [x] Double-clic sur le nom ou commande de palette active un éditeur inline.
- [x] Entrée/perte de focus valide, Échap annule et un nom vide est refusé sans perdre le nom précédent.
- [x] Synchroniser immédiatement le nom dans l’arborescence.
- [x] Ne jamais écraser un nom manuel par une mise à jour automatique.
- [x] Gérer les noms longs et la composition de texte sans validation prématurée.
