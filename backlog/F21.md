## Besoin utilisateur

Être prévenu lorsqu’une intervention devient nécessaire.

## Critères d’acceptation

- [x] Émettre une notification discrète et ciblée pour une nouvelle attente.
- [x] Éviter les doublons et changements automatiques de workspace ou de focus.
- [x] Permettre de rejoindre précisément le pane concerné.
- [x] Définir le choix de destination lorsque plusieurs panes attendent.
- [x] Définir un comportement utile lorsque le panneau est replié.
