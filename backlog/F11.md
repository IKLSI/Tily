## Besoin utilisateur

Utiliser l’application comme un terminal Windows complet.

## Critères d’acceptation

- [x] Lancer Windows PowerShell 5.1 par défaut ; proposer PowerShell 7, CMD et Git Bash lorsque les chemins sont configurés.
- [x] Charger le vrai profil avec alias, fonctions, modules et prompt.
- [x] Charger notamment wtr et rmwt depuis %USERPROFILE%\Documents\WindowsPowerShell\Microsoft.PowerShell_profile.ps1.
- [x] Supporter commandes libres, sélection, copier/coller, couleurs, Unicode et outils plein écran.
- [x] Suivre le dossier courant réel après cd et fonctions du profil.
- [x] Obtenir ce dossier par une intégration shell propre à Dock (variable d’environnement dédiée et séquence OSC émise par le prompt), compatible avec le profil et oh-my-posh, sans simuler WezTerm.
- [x] Signaler localement un shell introuvable avec relance ou choix alternatif, sans substitution silencieuse.
- [x] Valider redimensionnement et touches de contrôle avec les outils réels.

## Références

- [Spécifications complètes](https://github.com/MaximeRazafinjato/dock-terminal/blob/main/specifications-terminal.md), sections 8.
- Recette : R12, R13, R14.

## Dépendances fonctionnelles

Aucune dépendance fonctionnelle imposée.

## Points à préciser

VS Code est l’éditeur retenu. Le profil observé est celui de Windows PowerShell 5.1 ; le profil PowerShell 7 n’a pas été trouvé dans Documents\PowerShell et ne doit pas être supposé identique.

Aucune priorité ni échéance attribuée.
