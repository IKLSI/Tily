## Besoin utilisateur

Ouvrir un terminal sans formulaire et choisir un autre shell au besoin.

## Critères d’acceptation

- [x] Clic gauche sur « + » ouvre directement PowerShell.
- [x] Clic droit sur le même bouton affiche PowerShell, CMD et Git Bash dans un menu contextuel.
- [x] Le menu accepte flèches, Entrée, Échap, clic extérieur et Maj + F10.
- [x] Le nouvel onglet reprend le dossier réel du pane actif.
- [x] Aucun bouton séparé de choix du shell ; garder une action équivalente dans la palette.
