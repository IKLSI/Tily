## Besoin utilisateur

Organiser des terminaux dans des groupes libres, sans couche projet.

## Critères d’acceptation

- [x] Disposer d’un workspace par défaut et interdire les terminaux sans workspace.
- [x] Créer un workspace directement depuis le panneau et éditer son nom inline.
- [x] Permettre des onglets dans des dossiers sans rapport entre eux.
- [x] Renommer depuis le titre ou la palette ; Entrée/perte de focus valide, Échap annule, nom vide conserve le précédent.
- [x] Synchroniser le nom et la sélection entre en-tête et panneau.

## Points à préciser

Nom automatique selon le dossier ; le nom manuel reste prioritaire. Fermer le dernier onglet supprime le workspace ; confirmer la suppression explicite si des onglets ou processus sont actifs, puis arrêter les processus.

Aucune priorité ni échéance attribuée.
